# Security Policy

## Supported Versions

We release patches and security advisories for the following versions:

| Version | Supported |
|---|---|
| 2.x.x | Yes |
| 1.x.x | Security patches only |
| < 1.0.0 | No |

---

## Reporting a Vulnerability

The SentinelAI team takes the security of autonomous agent runtime environments seriously. If you discover a security vulnerability, please do not open a public issue.

Instead, please report vulnerabilities privately:

1. Email your findings to `security@sentinelai.dev` (or open a confidential GitHub Security Advisory).
2. Include the following details:
   - Type of vulnerability (e.g., prompt injection bypass, privilege escalation, PII exfiltration).
   - Step-by-step reproduction instructions or Proof-of-Concept payload.
   - Affected modules and configurations.
   - Suggested mitigations, if known.

### Response Timeline
- **Initial Acknowledgement**: Within 24 hours.
- **Triage & Severity Assessment**: Within 48 hours.
- **Patch Release & Public Advisory**: Coordinated disclosure within 30 days of confirmed fix.
